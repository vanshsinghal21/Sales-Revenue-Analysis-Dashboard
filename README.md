# Sales & Revenue Analysis Dashboard

## Project Overview

This project presents an interactive Sales & Revenue Analysis Dashboard built using Power BI.

The dashboard provides insights into:
- Total Revenue
- Total Orders
- Total Quantity Sold
- Average Revenue
- Product Performance Analysis
- Regional Sales Analysis
- Category-wise Revenue Distribution

## Dashboard Features

### KPI Cards
- Total Revenue
- Total Orders
- Total Quantity Sold
- Average Revenue

### Visualizations
- Monthly Revenue Trend
- Revenue by Product
- Revenue by Category
- Revenue by Region

### Interactive Filters
- Region Slicer
- Category Slicer

## Tools Used
- Power BI
- Excel Dataset
